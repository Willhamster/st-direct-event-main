▾世界书与上下文设置
默认注入常驻蓝灯。点击右侧按钮可自主勾选任意条目注入副 API，或直接修改/新增世界观设定。
默认仅注入 stat_data（MVU 等框架的角色状态与数值表），其余变量一律不注入。点击右侧按钮可按分支勾选更多内容或排除 stat_data 内的子分支；空值剪枝等规则也在弹窗中调整。检测到酒馆助手时读取角色卡与聊天变量，未安装时读取酒馆核心聊天变量；每次生成实时读取，以 $ 开头的隐藏变量不注入。
填写后，上下文只保留这些标签内的内容，标签外的文字（含无标签的普通消息）一律不发送。 这些标签的完整块（含标签内文字）将从上下文中删除；两者同时填写时先排除、后提取。

新建事件包
配置专属事件包：事件包名与至少一条风格（名称+提示词）填写完整后事件包按钮才会生效，档位可选。设置到一半可直接保存，主界面按钮会保持草稿置灰状态，随时点铅笔继续编辑。各区块的「复制范例」按钮可复制提示词范例（按内置风格/档位的写法给出，可直接使用或照此改写）。
导入 / 导出自定义事件包
导出：把自定义事件包打包成 JSON 发给其他用户即可共享（事件包本体即全部生效提示词，与预设工坊/事件包编辑器同源，对方导入后与你实际生效的完全一致）。导入：选择分享的 JSON 文件或直接粘贴文本；与现有事件包同名时会逐条让你选择覆盖或另存，编号前缀冲突时自动重新分配，不影响现有事件包与历史事件。
