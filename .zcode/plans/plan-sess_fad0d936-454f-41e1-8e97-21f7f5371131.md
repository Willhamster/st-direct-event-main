## 将「自动发送」复选框改为三选一模式（自动发送 / 仅填入对话框 / 不发送不填入）

### 背景
现在设置面板里 `自动发送` 是单个复选框（boolean）。玩家想生成后「只把事件编号填进输入框、不发送」，以便自己追加提示词后再手动发送——当前做不到。改成三选一。

### 数据模型
- 新增设置字段 `autoSendMode`，三值：`'auto'`（自动发送）/ `'fill'`（仅填入对话框，不发送）/ `'none'`（不发送也不填入）。
- 保留旧布尔 `autoSend` 的兼容：`getSettings()` 迁移——旧存档 `autoSend: true` → `'auto'`，`false` → `'none'`；新存档以 `autoSendMode` 为准。

### 改动点（全部在 index.js）

1. **DEFAULT_SETTINGS**（:112）：`autoSend: true` → `autoSendMode: 'auto'`（同时保留 `autoSend: true` 兼容旧代码读取）。

2. **getSettings()**（:376 附近）：把 `merged.autoSend = merged.autoSend !== false;` 改为迁移逻辑：
   - `merged.autoSendMode = (stored/ls 中 autoSendMode) ?? (旧 autoSend === false ? 'none' : 'auto')`，并校验三值合法性。
   - 同步 `merged.autoSend = merged.autoSendMode === 'auto'` 供旧路径读取。

3. **设置面板 HTML**（:970-973）：把复选框 `<input id="se-auto-send" type="checkbox">` 换成 `<select id="se-auto-send">`，三个 `<option value="auto|fill|none">`：
   - 自动发送（生成后自动发编号并暗送全文给 AI）
   - 仅填入对话框（填入事件编号，可追加提示词后手动发送）
   - 不发送也不填入（仅保存，之后从事件列表手动发送）
   附一行说明文案：填入模式可追加自己的提示词再发送。

4. **fillSettingsForm()**（:2986）：`setChecked('se-auto-send', s.autoSend !== false)` → `set('se-auto-send', s.autoSendMode || 'auto')`。

5. **collectSettingsForm()**（:3025）：`autoSend: checked('se-auto-send')` → `autoSendMode: val('se-auto-send') || 'auto'`（并校验三值）。

6. **sendEventTrigger()**（:7133）：增加第二个可选参数 `mode = 'auto'`：
   - `'auto'`：现状（填框 + 真正发送 + 激活 + 注入）。
   - `'fill'`：只做「校验 + 激活 + 注入 + 填框」，**不调用 sendTextareaMessage / 不点发送按钮**；填完后 return。toast 提示「已填入对话框，可追加提示词后手动发送」。

7. **generateAndSave()**（:3608）：`if (settings.autoSend && !signal?.aborted)` → 按 `settings.autoSendMode` 分支：
   - `'auto'` → `sendEventTrigger(event, sourceChatId, 'auto')`
   - `'fill'` → `sendEventTrigger(event, sourceChatId, 'fill')`
   - `'none'` → 不发送不填框（仅存档）

8. **handleGenerate() 的 toast**（:3489）：按模式显示不同文案：自动发送 / 已填入对话框 / 已保存可在事件列表发送。
